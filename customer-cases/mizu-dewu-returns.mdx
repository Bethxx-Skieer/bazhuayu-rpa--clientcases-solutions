## 2.业务问题

### 01.业务背景

作为深耕得物平台的潮流电商企业，米足电商经营着多个店铺账号，每日面对大量退货售后订单，其售后数字化背景如下：

- 系统范围：得物商家后台 + 聚水潭 ERP，2 大系统深度联动
- 账号数量：多个得物店铺账号（N 个），支持 Excel 批量导入与自动切换
- 原处理方式：逐个账号登录、逐个订单签收与退款，2 人专职售后

### 02.流程与问题

得物售后的链路横跨两个系统与多个账号，人工处理的效率与准确率都难以保证：

#### 多账号淹没
得物平台退货量大，人工逐个签收退款耗时耗力，多账号切换更让效率雪上加霜，售后团队每天被重复操作淹没。

#### 数据割裂
得物后台与聚水潭ERP数据割裂，需要人工比对应退数量与实退数量，判断哪些订单可以处理，极易出错且效率极低。

#### 资金风险
售后操作涉及资金退款，人工操作风险高，一旦出错可能造成资金损失，且操作留痕困难，出了问题难以追溯。

| 人工操作流程 | 具体步骤 | 问题 |
|-|-|-|
| 账号登录 | 逐个登录得物店铺账号，导出待处理退货订单 | 账号多、切换频繁，光重复操作大半天 |
| 跨系统比对 | 拿退回快递单号去聚水潭查询入库，比对应退与实退数量 | 逐笔比对慢，经常看错行、漏比对 |
| 订单筛选 | 人工判断哪些订单“应退数量=实退数量”可以处理 | 依赖经验判断，易错单 |
| 签收与退款 | 点击进入每个订单，确认信息后签收、再点退款 | 几百单即上千次点击，易退错金额或订单 |
| 记录与追溯 | 手工记录处理情况，事后人工回溯 | 留痕困难，异常难追溯 |

### 03.客户需求

- 多账号批量处理：机器自动登录所有账号，批量筛选并一键完成签收+退款，账号自动切换
- 双系统自动比对：得物订单与聚水潭快递信息自动核对，精准筛出“应退=实退”的订单
- 资金安全可审计：按预设规则标准化执行，操作全程留痕，可追溯、可审计、零差错

## 3.解决方案

针对上述痛点，米足电商引入八爪鱼 RPA，把“多账号登录 → 双系统比对 → 批量签收退款 → 日志留痕”串成一条全自动链路。

### 01.概述

|  | 说明 |
|-|-|
| 覆盖系统 | 得物商家后台 + 聚水潭 ERP，双系统深度联动，数据自动同步比对 |
| 覆盖账号 | 支持 Excel 批量导入，不限得物账号数量，自动切换处理，多店铺统一管理 |
| 处理环节 | 订单导出 → 快递查询 → 条件筛选 → 批量签收 → 批量退款 → 日志记录，全流程自动化 |
| 应用场景 | 退货签收、退款处理、多账号售后管理、售后数据统计、异常订单监控 |
| 运行节奏 | 按日自动执行，处理时效小时级，当日订单当日清零 |

**多账号一键切换，批量处理效率倍增**

过去，米足电商的售后团队每天要登录多个得物账号，逐个处理退货订单——先签收、再退款，一个账号处理完再切换下一个。几百单退回来，光重复操作就要花掉大半天时间，人力成本高且效率低下。八爪鱼RPA上线后，这一切彻底改变。

机器人自动读取Excel中的账号列表，逐个登录得物后台，自动导出待处理订单，筛选符合条件后批量签收、批量退款，处理完一个账号自动切换下一个，全程无需人工干预。不管是5个账号还是20个账号，机器人都能稳定高效地跑完，售后处理效率提升数倍。

**双系统智能比对，精准筛选可处理订单**

售后退款不是所有订单都能直接处理——必须确认商品已经退回仓库，也就是“应退数量=实退数量”才能操作。过去这个判断全靠人工：从得物导出订单，再去聚水潭查快递，一个一个比对，不仅慢，还经常看错行、漏比对。

八爪鱼RPA打通了得物商家后台与聚水潭ERP双系统：先从得物导出所有待处理订单，再拿着退回快递单号去聚水潭查询入库情况，通过内置脚本自动比对“应退数量”与“实退数量”，精准筛选出符合条件的订单。整个比对过程全自动，零人工判断，准确率100%（口径：应退数量与实退数量逐单比对）。

**签收退款全自动，售后流程零人工**

筛选出可处理订单后，接下来就是签收和退款操作。过去人工操作需要点击进入每个订单，确认信息后点签收、再点退款，一单下来就要好几步，几百单就是上千次点击。八爪鱼RPA将这一过程完全自动化。

机器人将筛选出的订单号批量导入得物后台查询，一键全选后批量签收，再一键批量退款，整个过程行云流水。从登录账号、导出订单、跨系统比对、筛选订单到批量签收、批量退款，全流程零人工干预，售后团队只需要查看最终的处理结果即可，彻底从重复劳动中解放出来。

**操作全程留痕，资金安全有保障**

售后退款直接涉及资金，每一笔操作都必须准确无误。人工操作时，偶尔会出现退错金额、退错订单的情况，不仅造成资金损失，还影响客户体验。八爪鱼RPA采用标准化执行模式，每一步操作都严格按照预设规则执行，不会出现人为失误。

同时，机器人会自动记录完整的操作日志——哪个账号、什么时间、处理了哪些订单、签收多少、退款多少，全部清清楚楚，可追溯、可审计。遇到异常情况自动暂停并报警，确保每一笔资金操作都安全可控。售后负责人每天打开报表就能看到全局处理情况，管理效率大幅提升。

### 02.方案优势

1. **多账号批量跑**：账号列表从 Excel 读取，登录、导出、签收、退款、切换全程自动，5 个还是 20 个账号都用同一套流程。
2. **双系统自动比对**：聚水潭快递信息自动核对应退与实退数量，精准筛出可处理订单，零人工判断。
3. **批量操作省点击**：订单号批量导入后一键全选，批量签收 + 批量退款，几百单不再需要上千次点击。
4. **全程留痕可审计**：每一步操作自动记日志，异常自动暂停报警，资金操作安全可控、结果可追溯。
